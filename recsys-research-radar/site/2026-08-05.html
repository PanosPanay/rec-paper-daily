  • 原始链接：https://arxiv.org/pdf/2607.28971v1
  • 中文摘要：大规模推荐系统常用对比学习进行用户建模，标准 in-batch negative 隐含假设是任意用户都可能看到任意物品。但在 Karrot 等本地社区平台上，曝光受到地理范围约束，许多用户-物品组合实际上不可能发生，却仍被当作负样本，稀释了训练信号。RCBS 构造区域同质的小批次，让用户主要与真实可曝光的物品进行对比，从而用可行且更困难的负样本替代不可能负样本。
  • 核心贡献：提出区域约束批采样 RCBS，让对比学习的负样本遵循真实曝光约束，并将用户表示用于信息流排序、召回和广告排序。
  • 方法：召回/检索, 排序, 方法说明待补充, 广告排序, 对比学习
  • 局限性：本地社区平台的曝光具有明显地域约束，许多用户-物品对按设计不可能曝光，却会在普通对比学习中被误当成负样本。
  • 未来方向：原文方向：用区域同质的小批次构造更符合真实曝光空间的负样本，让用户主要与其可能看到的物品进行对比。
  • 拓展阅读：用于 YouTube 推荐的深度神经网络（经典的候选生成与排序两阶段工业架构）；用于点击率预测的深度兴趣演化网络（把用户兴趣演化引入序列行为建模）
  • 数据集/基准：未明确说明
  • 主题：召回与候选生成, 排序、粗排与重排, 序列推荐与用户建模, 广告与市场排序
  • 证据：matched keywords: ads ranking, ranking, retrieval, user modeling；categories/venue: cs.IR, cs.LG
  • 小型实验：在小型隐式反馈矩阵上，对比双塔召回基线与论文提出的召回信号。

Think2Go：结合 LLM 推理的生成式下一地点推荐

  • 原文标题：Think2Go: Generative Next POI Recommendation with LLM Reasoning
  • 原始链接：https://arxiv.org/pdf/2607.28997v1
  • 中文摘要：下一兴趣点推荐从历史签到中挖掘用户行为偏好，以预测用户接下来可能到访的地点。Think2Go 指出现有方法依赖浅层上下文和手工特征交互，难以处理稀疏、复杂的移动模式；而 LLM 在语义标识符单独训练时又缺少对 SID 的深入理解。该框架统一监督微调与基于强化学习的推理，在记忆用户行为的同时进行自适应探索，并通过测试时计算扩展捕捉多样的时空模式。
  • 核心贡献：提出生成式下一 POI 推荐框架，把 SID 理解、监督微调、强化学习推理和测试时计算扩展结合起来。
  • 方法：校准, 强化学习, 探索, 大语言模型（LLM）
  • 局限性：用户移动模式具有稀疏性和复杂性，非推理模型难以捕捉深层意图；LLM 若缺少对独立训练 SID 的理解，表现也会受限。；生成式推理和测试时计算扩展可能增加在线延迟与成本，原始摘要没有给出完整的服务预算和消融细节。
  • 未来方向：下一 POI 推荐的长期方向是从历史签到中持续挖掘个性化的行为偏好模式。；现有方法主要依赖浅层上下文和手工特征交互，仍需要更强的时空序列与语义建模。；原文方向：通过更好地理解 SID 表示，并用测试时计算扩展探索多样时空模式，提升生成式下一地点推荐。
  • 数据集/基准：未明确说明
  • 主题：排序、粗排与重排, 探索、强化学习与因果评估
  • 证据：matched keywords: calibration, exploration, reinforcement learning；categories/venue: cs.IR
  • 小型实验：在公开点击数据子集上，分别训练加入和不加入该特征/目标的小型重排模型。

EvoReason：原语引导的在线蒸馏与自演化推理，用于生成式推荐中的隐式推理

  • 原文标题：EvoReason: Self-Evolving Reasoning Primitive-Guided On-Policy Distillation for Latent Reasoning in Generative Recommendation
  • 原始链接：https://arxiv.org/pdf/2607.29010v1
  • 中文摘要：生成式推荐可以通过增强推理提升效果，而隐式推理把中间过程编码为紧凑的连续表示，适合对延迟敏感的部署。现有方法通常直接把原始思维链轨迹蒸馏到隐式表示中，但推荐推理轨迹过程多样、表达冗余且路径不稳定，导致监督信号难以迁移。EvoReason 从高质量 agent 推荐轨迹中抽取可复用的推理原语，把它们作为结构化教师推理的伪工具，再通过原语引导的在线蒸馏，让教师监督与学生的隐式推理空间自适应对齐。
  • 核心贡献：提出自演化隐式推理框架，从推荐轨迹中提取推理原语，并用在线策略蒸馏持续对齐显式教师监督和学生隐式表示。
  • 方法：方法说明待补充, 延迟优化, 知识蒸馏
  • 局限性：推荐推理轨迹包含多样、冗余且不稳定的推理过程，直接使用原始思维链监督不利于学习可迁移的隐式推理表示。；该方法依赖高质量 agent 轨迹和在线蒸馏闭环，训练成本、教师质量和推理原语覆盖范围可能成为复现瓶颈。
  • 未来方向：未明确说明
  • 拓展阅读：GenRec：迈向 Netflix 的 LLM 原生推荐（业界大模型原生推荐架构实践）
  • 数据集/基准：未明确说明
  • 主题：生成式/大模型推荐, 服务、延迟与基础设施
  • 证据：matched keywords: generative recommendation, latency；categories/venue: cs.IR
  • 小型实验：在采样物品上，对比小型 LLM/RAG 推荐提示与非生成式召回-排序链路。
