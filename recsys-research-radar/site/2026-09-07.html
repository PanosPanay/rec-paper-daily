  • EPIC 语义 ID 扩散推荐的下一物品条件实验
  • 假设：显式后验物品条件能在保持简单生成式基线成本可控的同时提升下一物品预测。
  • 观察：EPIC 的标题指向在语义 ID 扩散推荐中显式注入后验物品条件；由于本轮只取得备用索引，先在小型序列任务上验证方向，不把摘要片段当作完整结论。
  • 实验：在 MovieLens-small 或合成会话上，实现 SASRec-lite 与简化语义 ID 生成基线，再加入显式后验物品条件，比较下一物品预测。
  • 基线：流行度、item-kNN 和 SASRec-lite
  • 数据集/设置：MovieLens-small；按时间切分训练、验证和测试，额外报告冷启动物品切片
  • 指标：HitRate@10、NDCG@10、冷启动切片和单次推理耗时
  • 预计耗时：笔记本 CPU 上运行玩具版本预计少于 30 分钟
  • 失败模式：离线指标提升无法复现；收益只出现在高流行度用户或物品；复杂度增加导致延迟或稳定性变差
  • HypRQ-VAE 双曲索引的长尾推荐实验
  • 假设：双曲物品索引能够更好地表达长尾层级结构，在不明显牺牲总体排序质量的情况下提升尾部物品覆盖。
  • 观察：HypRQ-VAE 关注双曲空间物品索引与长尾感知生成式推荐；可在流行度分层的公开数据上比较普通语义 ID 与双曲索引的尾部收益。
  • 实验：在物品按交互量分层的 MovieLens-small 上，对比普通 VQ-VAE/语义 ID 索引与简化双曲索引，测量尾部物品召回和覆盖。
  • 基线：普通 VQ-VAE 或语义 ID 生成式推荐基线
  • 数据集/设置：MovieLens-small；按物品交互量划分头部、中部和尾部，保持候选数量与训练步数一致
  • 指标：Recall@50、NDCG@10、尾部 Recall、目录覆盖率和生成错误率
  • 预计耗时：笔记本 CPU 上运行玩具版本预计少于 30 分钟
  • 失败模式：离线指标提升无法复现；收益只出现在高流行度用户或物品；复杂度增加导致延迟或稳定性变差
  • 重复查询审计大语言模型品牌推荐的稳定性与偏差
  • 假设：固定提示模板并重复查询，可以揭示传统单次离线评估看不到的品牌推荐稳定性和流行度偏差。
  • 观察：骰子滚动法关注对大语言模型品牌推荐进行重复查询审计；可在小型品牌或物品目录上测量推荐稳定性、流行度偏差和目录覆盖，而不是直接假定其协议已适用于传统推荐。
  • 实验：固定用户偏好提示和候选品牌集合，改变随机种子并重复查询，记录推荐集合的一致性、品牌曝光和流行度分层结果。
