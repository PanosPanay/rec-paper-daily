曝光份额预测：排序系统的离线评估任务

  • 原文标题：Impression Share Prediction: An Offline Evaluation Task for Ranking Systems
  • 原始链接：https://arxiv.org/pdf/2608.16872v1
  • 中文摘要：离线评估是排序模型进入线上 A/B 测试前的重要环节，但常见离线指标主要衡量预测准确性，只是下游效用的替代指标。一个模型可能提升离线指标，却把曝光重新分配到不同优化目标桶中，导致真实业务效用下降；现有离线方法很难在上线前显式暴露这种曝光份额变化。论文提出‘曝光份额预测’任务：给定一个候选排序模型，预测它会在点击、视频观看等不同目标桶之间产生怎样的曝光分布。由于候选模型尚未服务真实流量，这本质上是反事实问题。作者建立排序模型预测、投放容量与曝光分配之间的结构因果模型，并提出基于候选模型早期交互置信信号和当前系统状态的统计学习框架，从历史数据预测曝光份额。论文在多个排序模型族的数据上报告，随机森林相较常数基线对训练中见过的模型将 L1 误差降低 49%；具体线上迁移仍需核验。
  • 核心贡献：把候选排序模型将产生的曝光份额分布定义为新的离线评估目标，并用结构因果模型和统计学习框架在上线前预测不同业务目标桶的曝光分配。
  • 方法：排序, 反事实学习/评估, 因果推断, 离线评估, 在线评估, 竞价与广告分配
  • 局限性：未明确说明
  • 未来方向：需要进一步验证曝光份额预测在未见排序模型、不同广告/推荐目标桶和真实线上流量下的稳定性，以及预测分布与长期业务效用之间的关系。
  • 数据集/基准：未明确说明
  • 主题：排序、粗排与重排, 探索、强化学习与因果评估, 评估、去偏与公平性, 广告与市场排序

UniDot：统一大规模推荐中的序列建模与特征交互网络

  • 原文标题：UniDot: A Unified Network for Sequence Modeling and Feature Interaction in Large-scale Recommendation
  • 原始链接：https://arxiv.org/pdf/2608.16797v1
  • 中文摘要：工业推荐系统长期沿着两类模型演进：一类在多字段用户/物品特征上建模特征交互，另一类在用户行为历史上建模序列。生产系统通常只把两者松散组合。UniDot 从因子分解机（FM）视角统一它们：协同过滤中的 Embedding 内积和注意力中的 Query-Key 点积本质上是同一个计算原语，因此可以用一次 token 点积同时支撑特征交互和序列建模。方法把非序列字段与多域行为序列 token 化到共享空间，在单一宏模块中并行运行 token mixing 总线和序列检索总线，其中物品 token 交叉注意力读取行为历史；两条总线通过 MLP-Mixer 融合逐层交换状态，同时由 FM Highway 将显式的逐层点积交互绕过残差堆栈直接连接到分类器。论文面向点击后转化预测，强调统一模型结构与在线推理效率。
  • 核心贡献：提出 UniDot，用共享 token 空间和点积原语统一多字段特征交互与用户行为序列建模，并通过并行序列检索、MLP-Mixer 融合和 FM Highway 构建面向生产的转化预测架构。
  • 方法：召回/检索, 延迟优化, 协同过滤
  • 局限性：未明确说明
  • 未来方向：进一步验证统一序列与特征交互架构在不同召回规模、用户行为长度和在线服务约束下的质量、延迟与内存权衡。
  • 拓展阅读：用于 YouTube 推荐的深度神经网络（经典的候选生成与排序两阶段工业架构，可作为评估 UniDot 如何接入现有召回、排序和服务链路的架构参照。）
  • 数据集/基准：未明确说明
  • 主题：召回与候选生成, 服务、延迟与基础设施
  • 证据：matched keywords: latency, retrieval；categories/venue: cs.IR, cs.AI
  • 小型实验：在小型隐式反馈矩阵上，对比双塔召回基线与论文提出的召回信号。

GEO-Flag：检测与度量生成式引擎优化网页内容

  • 原文标题：GEO-Flag: Detecting and Measuring GEO-Optimized Web Content
  • 原始链接：https://arxiv.org/pdf/2608.16824v1
  • 中文摘要：生成式引擎优化（GEO）通过修改网页内容，提高页面被生成式搜索引擎选中和引用的概率。这可能让权威性或相关性不足的页面获得不成比例的可见度，甚至让薄弱或错误的信息看起来获得了充分支持。与展示多个竞争来源的传统搜索不同，生成式搜索会直接合成答案，进一步放大来源溯源和权威性判断的风险。论文提出 GEOFlagBench 基准，包含 3,200 个网页、400 个查询、4 个领域和 8 类 GEO 优化器，用于系统评估 GEO 检测方法。最强基线的总体 F1 达到 0.880，但按优化器和作者条件评估时暴露出明显弱点，并可能依赖作者相关的捷径特征。作者进一步提出干预配对训练（IPT），监督模型区分 GEO 干预与非 GEO 的 AI 润色；在 ModernBERT 上，IPT 将 F1 从 0.862 提升到 0.944，最差组准确率也得到改善，具体完整结果需核验原文。
  • 核心贡献：构建覆盖 3,200 个网页、400 个查询、4 个领域和 8 类 GEO 优化器的 GEOFlagBench，并提出干预配对训练来降低 GEO 检测对作者和数据捷径的依赖。
  • 方法：召回/检索
  • 局限性：针对 GEO 优化网页的系统化检测方法仍处于探索阶段，现有检测器可能在跨作者、跨优化器和跨领域场景中失效。
  • 未来方向：生成式搜索直接合成答案而不是并列展示来源，因此还需要继续研究来源溯源、权威性判断和用户可验证交互机制。
  • 拓展阅读：用于 YouTube 推荐的深度神经网络（经典的候选生成与排序两阶段工业架构，可用于对照生成式搜索中的候选选择、来源质量和排序评估。）
  • 数据集/基准：未明确说明
  • 主题：召回与候选生成
  • 证据：matched keywords: retrieval；categories/venue: cs.LG, cs.CR, cs.IR
  • 小型实验：在小型隐式反馈矩阵上，对比双塔召回基线与论文提出的召回信号。
